# ADR-003 – Authentification & autorisation via JWT

- Statut : Acceptée
- Date : 29/11/2025

## Contexte

L'interface d'administration doit être protégée :

- seuls les administrateurs peuvent créer / modifier les questionnaires,
- le frontend dpot être restraint en fonction de l'utilisateur.

## Décision

Nous utilisons **LexikJWTAuthenticationBundle** pour gérer :

- la génération de tokens JWT lors du login,
- la protection des routes d'administration via un firewall JWT,
- l'autorisation via JWT.

## Alternatives envisagées

- Sessions PHP classiques (cookies de session) :
  rejeté car développement en REACT, une session irait contre l'intérêt d'utiliser react/
- Pas d'authentification :
  rejeté pour des raisons logiques de sécurité.

## Conséquences

**Positives**

- Routes admin sécurisées,
- Symfony gère ça facilement

**Négatives / limites**

- Nécessite de gérer la génération et la rotation des clés JWT.
- Rend le développement moins explicite, difficile à comprendre.
