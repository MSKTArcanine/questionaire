# ADR-002 – Modélisation de l'arbre de questions via `Choice → nextQuestion`

- Statut : Acceptée
- Date : 24/11/2025

## Contexte

Navigation en arborescence ROOT -> Node -> Leaf
Chaque réponse peut amener à une question différente ou terminer le parcours.

## Décision

L'arbre est modélisé ainsi :

- `Questionnaire` contient plusieurs `Question`.
- `Question` contient plusieurs `Choice`.
- Chaque `Choice` possède un lien optionnel vers une `nextQuestion`
  (Cf. Doctrine `Entity/`).

La navigation se fait donc en suivant les liens `Choice → nextQuestion`.
Une entité `AnswerSession` conserve la question courante et les réponses déjà données.

## Alternatives envisagées

- Stocker l'arbre complet dans un JSON ou une structure imbriquée :
  rejeté car plus difficile à interroger en SQL et à maintenir via Doctrine.
- Utiliser une table séparée pour représenter les relations Question→Question :
  rejeté pour ce test, trop verbeux.

## Conséquences

**Positives**

- Simple à mettre en place
- Facile à tester

**Négatives / limites**

- Relation en boucle possible => Règles métiers à mettre en place
- Adapter le format de création aux admins car très vite trop grand.
